NivelIndicadorDificultad para el atacante al cambiarlo

Consultas de ejemplo en SIEM

# Splunk (SPL): intentos fallidos de inicio de sesión por usuario y origen
index=* EventCode=4625
| stats count by Account_Name, Source_Network_Address
| sort - count

# Elastic (KQL, en Kibana Discover)
event.code: 4625 and winlog.computer_name: "WIN-01"

Los nombres de los campos dependen de cómo se ingestaron los datos. Revisa siempre la lista de campos disponibles antes de escribir la consulta.

Filtros de visualización de Wireshark

arp.duplicate-address-detected                  # posible ARP spoofing
frame contains "password"

Estructura de una regla de Snort

alert tcp any any -> any 80 (msg:"GET a /admin"; content:"GET"; content:"/admin"; sid:1000001; rev:1;)

# Modo IDS leyendo un PCAP
sudo snort -c /etc/snort/snort.conf -r captura.pcap -A console -q

Orden de la cabecera: acción, protocolo, IP y puerto origen, dirección, IP y puerto destino, y entre paréntesis las opciones.

Registros de Linux

/var/log/auth.log        # Debian/Ubuntu: autenticación, sudo, ssh
/var/log/secure          # RHEL/CentOS: equivalente
/var/log/syslog          # eventos generales
/var/log/audit/audit.log # auditd
journalctl -u ssh        # registros de un servicio con systemd
grep "Failed password" /var/log/auth.log
last ; lastb             # sesiones correctas y fallidas
